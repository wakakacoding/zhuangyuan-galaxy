# N1-04 地图来源整改记录

日期：2026-10-18
状态：部分完成。公开分发许可尚未取得，不能宣布地图来源问题已关闭。

## 已做

1. `scripts/build-geo-maps.ts` 在切片时排除 `TYPE_CH == 非政区国土`。
   自查报告指出唐至明七份切片因此带入「流求 / 琉球 / 台湾」本岛面。
   清 1820 年的台湾府是府级政区，类型不是「非政区国土」，这条过滤不会删掉它。
2. 辽的 `map_note` 改为：当前底图与宋图同源，是 1111 年北宋政区，不是辽的疆域，也不叠加现代省界。

## 未做，且不能由本次自行决定

- 仓库里现有的八份 `public/data/maps/*.json` 没有在本机用 CHGIS 原始数据重切。没有原始 shp 时，构建脚本会沿用已有切片。
- CHGIS V6 的使用条款写明不得再分发。公开仓库和 GitHub Pages 仍在分发这些切片。
  可选路径只有三条：取得书面分发许可、换成许可明确的数据、或停止公开这些切片。
  本记录不选择其中任何一条，也不删除历史提交。
- 历史地图没有审图号。页面上的历史疆域仍是学术示意，不作为国界依据。

下一次用原始数据重建切片后，须核对：七朝不再含「非政区国土」的台湾本岛面，清图仍保留台湾府。
